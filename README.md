<h2 id="introduction">🌟 Introduction</h2>

This repository demonstrates the **Strategy** design pattern in C#. A `PlayerController` swaps between interchangeable companion behaviours (`BearCompanion`, `CrocodileCompanion`, `DogCompanion`) at runtime through a shared `Companion` abstraction.

<h2 id="installation">📦 Installation</h2>

1. Clone or download the project.
    ```bash
    git clone https://github.com/lncodes/design-pattern-strategy.git
    ```

2. Open `c#/src/Strategy.sln` in Visual Studio or Rider.

> Targets .NET Core 3.1; install that SDK, or retarget the project to a current .NET version.

<h2 id="usage">🧑‍💻 Usage</h2>

- Build:
    ```bash
    dotnet build "c#/src/Strategy.sln"
    ```

- Run the unit tests:
    ```bash
    dotnet test "c#/test"
    ```
